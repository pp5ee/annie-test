# Knicks Scores Website

## Project Standards

### Technology Stack
- Vanilla HTML5, CSS3, JavaScript (ES6+)
- No build tools or bundlers required
- Static site suitable for GitHub Pages

### File Structure
- index.html - Main page
- styles.css - All styles
- app.js - Application logic

### Design System
**Colors:**
- Knicks Blue: #006BB6 (primary)
- Knicks Orange: #F58426 (accent)
- Background: #FFFFFF
- Text: #1A1A1A (primary), #666666 (secondary)
- Card Background: #F8F8F8

**Typography:**
- System font stack for body text
- 16px base font size
- Adequate line height (1.5+) for readability

### Code Style
- Use semantic HTML5 elements
- CSS variables for colors
- Modular JavaScript functions
- Try/catch for error handling
